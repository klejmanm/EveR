# EveR
Eversolo DMP A6 remote control app

Python app for remote control Eversolo DMP A6 player, using zidoo API (https://www.zidoo.tv/Support/developer.html).

# Run app:
Run app via command line: python3 ever.py

Linux:
Add executable attribute to app: chmod a+x ever.py
Run app from commandline or via gui: ./ever.py

# Usage
In Configuration/Main tab enter IP of your EverSolo DMP A6, and click Refresh collection button to synchronize your collection of Artists / albums / tracks from device.
Double click on track name to start playing it.
